Privacy Policy

My List · Effective November 25, 2026

My List is a dailies and todos app published by Horothenic. The list is a file you own. This page says what the app handles and where that information stays.

The list

Each item can have a title, a description, checklist steps, dates, and whether it is done. That text is the list. My List does not run a server that stores it.

On this device the list is kept in the browser’s storage. You can also keep it in a file you choose on this device. If you pick Google Drive as the source, the list is one file named my-list.json in your Drive.

Google Drive

Drive is optional. Sign-in uses your Google account. The app asks only for permission to create and update files that it opens with you. It uses that permission for my-list.json. It does not read the rest of your Drive, and it never receives your Google password.

The sign-in token stays in this browser so the app can save that file. It is removed when you leave Drive as the source, or when the browser session ends.

My List’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

What this site does not collect

The site does not sell information, show ads, or use an analytics service. The last phone tab you opened is remembered on that device only, and it is not part of the list file.

GitHub Pages hosts the app itself. Your list is not part of that hosting.

Your choices

You can keep the list in a local file and never sign in. You can disconnect Google Drive from Source. You can delete my-list.json from your Drive. You can remove the site’s saved data from the browser, or remove the home-screen icon.

Changes

If this policy changes, the new version will be on this page with a new date.
